One training step

The heart of train.py. This eight-stage cycle repeats max_steps times. The teal stages carry activations forward to a scalar loss; the amber stages send gradients backward and turn them into a weight update.

Everything around the loop

What train() does before and after the cycle above — building the pieces once, then persisting progress.

1

Resolve device resolve_device()

"auto" → MPS on Apple Silicon, else CUDA, else CPU.

2

Memory-map the corpus np.load(mmap_mode="r")

Pre-tokenized .npy token arrays for train & val — never loaded whole into RAM.

3

Build the sampler DataLoading

Draws random contiguous windows on demand to form each [batch, context] batch.

4

Build the model TransformerLM(...)

Embedding + N decoder blocks + final norm + LM head, moved .to(device).

5

Build the optimizer AdamW(model.parameters())

Learns betas, eps, decoupled weight decay; its lr gets overwritten each step by the schedule.

6

Optionally resume load_checkpoint()

Restores model + optimizer state and returns the step to continue from.

7

Run the step cycle → periodically evaluate() + save_checkpoint()

evaluate() averages val cross-entropy under no_grad/eval(); checkpoints land on an interval and once more at the end.

03

Inside model(inputs)

The forward pass of TransformerLM. Token IDs enter as integers and leave as a distribution over the vocabulary. Shapes use the defaults: B=32, T=256, d=512, vocab=10 000, L=4.

04

Inside self-attention

What MultiHeadSelfAttention does to one [B, T, 512] stream: project to Q/K/V, split into 16 heads of width 32, rotate Q and K with RoPE, then run masked scaled-dot-product attention and merge back.

05

Component reference

Every file in cs336_basics, grouped by the role it plays in the loop above.

Model layers

forward TransformerLM.py Top-level module: embedding → blocks → final norm → LM head. embed → L×block → norm → linear
forward TransformerBlock.py One pre-norm decoder layer with two residual sublayers. x+Attn(ln1 x); +SwiGLU(ln2 ·)
forward Embedding.py Integer-array lookup into a learned [vocab, d] table. weight[token_ids]
forward Linear.py Bias-free matmul; truncated-normal init. x @ Wᵀ
forward RMSNorm.py Root-mean-square normalization with a learned gain, in fp32. x / rms(x) · g
forward SwiGLU.py Gated feed-forward network with a SiLU gate. W2( SiLU(W1 x) ⊙ W3 x )

Attention

forward MultiHeadSelfAttention.py Q/K/V projection, head split, RoPE, causal SDPA, merge, output proj. 16 heads × 32 dims
forward ScaledDotProductAttention.py Masked attention over one set of heads. softmax(QKᵀ/√d_k + mask) V
forward RotaryPositionalEmbedding.py Rotates Q/K by position using cached cos/sin buffers. even/odd pair rotation
forward Softmax.py Max-shifted softmax for numerical stability. exp(x−max) / Σ

Loss, gradients & schedule

forward CrossEntropy.py Log-sum-exp cross-entropy, averaged over all positions. −log p[target], mean
backward GradientClipping.py Rescales all grads in place when the global L2 norm exceeds the cap. g · min(1, max_norm/‖g‖)
schedule CosineLRScheduling.py Linear warmup, then cosine decay to a floor LR. warmup → cos → min_lr

Optimizer & orchestration

backward AdamW.py Adam moments + bias correction with decoupled weight decay. m,v → p −= lr·m̂/(√v̂+ε)
driver train.py Arg parsing, device, model/opt build, the step loop, eval & checkpoints. the whole loop
data DataLoading.py Samples random contiguous windows into input/target batches. x=data[i:i+T]; y=shift+1
io Serialization.py Saves/loads model + optimizer + step for pause & resume. torch.save / load

Upstream — data preparation (offline, before training)

prep train_bpe.py Trains the byte-pair-encoding merges over the raw corpus. bytes → merges → vocab
prep tokenizer.py Encodes text to token IDs; the result is saved as the .npy the loader mmaps. text → ids → .npy
